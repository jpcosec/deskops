# Átomos, pills y tareas guardan el dónde como punteros

## Answer

AtomDoc, PillDoc, TaskDoc y AtomAdrDoc tienen el campo pointers con tres clases: doc:<Model>:<id>, tag:<namespace>:<value> y code:<path>::<qualified_name>[~N]; un puntero mal formado se rechaza nombrando la clase esperada.
